FPS+++++ Detector for People Playground
A lightweight, browser-based tool designed to scan your local People Playground mod folder and detect mods infected with the FPS+++++ malware.

🤖 Developer's Note: This project was "vibecoded" (built heavily with AI assistance). The codebase might be unconventional, but it gets the job done. If you are an experienced developer and want to clean up the code or improve performance, pull requests are absolutely welcome!

Features
Browser-Based Scanning: Runs entirely locally via FPS+++++ Detector.html. Your files are never uploaded to an external server.

Fast Detection: Quickly parses your mod files to isolate the infected ones.

Simple Interface: Select your folder, click upload, and get instant results.

⚠️ Prerequisite: Recovering Lost Mods
If your mods have completely disappeared from your game folder, you must recover them from your Steam Workshop directory before scanning.

You can find your downloaded Workshop mods here:
C:\Program Files (x86)\Steam\steamapps\workshop\content\1118200

How to Use
Move your mods: Copy all of your recovered mods from the Workshop directory into your local People Playground mods folder located at:
C:\Program Files (x86)\Steam\steamapps\common\People Playground\Mods

Launch the detector: Double-click the FPS+++++ Detector.html file. It will open safely in a new tab in your default web browser.

Select your folder: Click the folder selection/upload button on the web page.

Target the Mods folder: Navigate to and select your local mods folder (C:\...\People Playground\Mods) and confirm the upload. (Note: Browsers will ask for permission to view these files; this is normal and safe).

Review results: The detector will quickly scan through all of your mod files and output a list of any mods currently infected with FPS+++++.

Troubleshooting
My browser is blocking the folder upload: Ensure you are using a modern browser (Chrome, Edge, Firefox, Brave) and that you click "Allow" when the browser prompts you for permission to view local files.

The path doesn't exist: If you have Steam installed on a different drive (e.g., D:\), you will need to replace C:\Program Files (x86) with your custom Steam library path.
